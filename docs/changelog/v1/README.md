# v1 系列 - 初始版本

**時間:** 2024-01-05

---

## 📌 版本概述

專案的第一個版本，建立核心記帳功能與童話風格設計系統。使用 localStorage 作為資料儲存，奠定整個專案的基礎架構。

---

## 🎯 主要功能

### 核心記帳功能
- 基礎記帳（金額、項目、分類、備註）
- 智能結算功能（自動計算欠款）
- 多帳本管理
- 多分類標籤系統
- 自訂分類管理

### 視圖與分析
- 時間軸視圖（按日期顯示交易記錄）
- 日曆視圖（月曆模式瀏覽）
- 分析頁面（統計與篩選）

### 設計系統
- 童話風格色彩配置（馬卡龍色系）
- 手寫字體（Caveat）
- 繪本風格帳本展示
- 水彩風格視覺效果
- 流暢的動畫過渡

---

## 🛠️ 技術架構

- **前端:** HTML5 + CSS3 + Vanilla JavaScript
- **資料儲存:** localStorage
- **樣式框架:** Tailwind CSS (CDN)
- **字體:** Google Fonts (Caveat)
- **圖標:** Material Symbols Icons
