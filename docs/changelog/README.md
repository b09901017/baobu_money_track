## 🎯 版本號規則

- **Major** (x.0.0) - 重大架構變更、不相容更新
- **Minor** (0.x.0) - 新功能、功能改進
- **Patch** (0.0.x) - Bug 修復、小調整

---

## 📝 更新類型

- 🔥 新增 (Added) - 新功能
- 🔄 變更 (Changed) - 現有功能的變更
- 🐛 修復 (Fixed) - Bug 修復
- 🚀 重構 (Refactored) - 代碼重構
- ✨ 改善 (Improved) - 效能或體驗改善
- 🔐 安全性 (Security) - 安全性改進
- 📚 文檔 (Documentation) - 文檔更新
