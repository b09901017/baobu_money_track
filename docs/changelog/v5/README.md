# v5 系列 - 即時同步與體驗優化

**時間:** 2026-01-06 ~ 2026-01-09

---

## 📌 版本概述

專案最成熟的階段，實現即時同步架構、離線支援、通知系統、沉浸式體驗優化，以及 Android 原生 APK 建置。功能與體驗全面升級。

---

## 🎯 主要功能

### v5.0-5.2 架構升級與編輯功能
- **v5.0.0** 🚀 即時監聽與離線支援
  - Firebase Offline Persistence（IndexedDB）
  - 即時監聽（onSnapshot）
  - 餘額管理系統（Firestore Transaction）
  - ListenerManager、NetworkMonitor、BalanceManager
- **v5.1.0** ✏️ 編輯交易功能
- **v5.1.1** 🐛 巢狀結構修復
- **v5.2.0** 📊 帳本統計自動初始化

### v5.3-5.5 設計優化與通知系統
- **v5.3.0** 🎨 馬卡龍貼紙風格（類別選擇按鈕）
- **v5.4.0** 🔔 活動記錄 & 通知系統
  - 智能通知規則（3 天前以上補記、修改、刪除）
  - 可愛通知文案
  - 右上角鈴鐺 + 側滑面板
- **v5.5.0** ✨ 通知中心升級
  - 智能簡述（金額變更、名稱變更等）
  - 詳情彈窗（變更前後對比）
  - 分頁載入

### v5.6-v5.8 UI/UX 與離線防護
- **v5.6.0** 🎨 UI/UX 大升級
  - 主頁時間軸折疊/展開
  - 統計摘要卡片
  - 日曆頁面 Segmented Control
- **v5.6.1** 🐛 時間軸交互優化
- **v5.6.2** 🐛 通知層級與初始化修復
- **v5.7.0** 📚 帳本拖曳排序
- **v5.7.1** 🤖 Android APK Google 登入修復
- **v5.7.2** 🤖 Android 自動化建置腳本
- **v5.8.0** 🎨 手機版 UI 優化 + Android 返回鍵
- **v5.8.1** 🔒 離線防重複提交機制
- **v5.8.2** 🔒 擴展防重複至編輯與刪除

## 🛠️ 技術亮點

### 即時同步架構
- onSnapshot 即時監聽
- IndexedDB 離線持久化
- ListenerManager 統一管理
- 訂閱-發布模式

### 餘額管理系統
- 餘額持久化（避免每次重算）
- Firestore Transaction（並發安全）
- 增量更新（O(n) → O(1)）
- BalanceManager 統一管理

### 離線防護
- 表單提交防抖
- 客戶端操作去重
- 操作指紋追蹤
- 友善離線提示

### Android 原生 APK
- Capacitor 整合
- Firebase Authentication 原生配置
- 震動回饋系統
- 返回鍵智能處理
- 全螢幕沉浸式體驗
