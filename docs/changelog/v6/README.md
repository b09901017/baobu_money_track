## 📖 版本概覽

v6 系列的核心理念是「**回歸本質、專注核心**」。經過 v5 系列的功能探索與實驗，我們在 v6 做出重大決策：移除結算功能系統，專注於提供最佳的記帳體驗。

### 🎯 設計哲學

**少即是多（Less is More）**
- 專注於記帳的核心價值：快速記錄、清楚餘額、智能分析
- 移除使用頻率低但維護成本高的功能
- 保持程式碼簡潔與可維護性

**使用者導向（User-Centric）**
- 基於實際使用情境做出功能取捨
- 優化最常用的操作流程
- 降低學習成本與認知負擔

## 💡 給開發者的話

v6.0.0 是一個重要的轉折點。我們學到：

1. **功能不是越多越好**
   - 每個功能都有維護成本
   - 複雜度是指數級增長的
   - 使用者需要的是簡單可靠，而非花俏功能

2. **Git 是強大的時間機器**
   - Interactive Rebase 可以重寫歷史
   - 備份分支是最好的保險
   - 勇於回退錯誤的決策

3. **文檔是未來的自己的禮物**
   - 詳細記錄決策過程
   - 保留完整的變更軌跡
   - 方便未來回顧與參考

讓我們在 v6 系列專注於打磨核心體驗，為使用者提供最簡潔、最可靠的記帳工具！
