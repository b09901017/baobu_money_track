# v6.0.0 - 重大架構重整（移除結算功能）

**發布日期：** 2026-01-11

---

## 🎯 版本重點

### 重大決策：移除結算功能系統

經過實際使用測試與需求評估，決定回退並移除整個結算功能系統（v5.10.0），回歸到更簡潔的核心記帳體驗。

**移除原因：**
1. **功能複雜度與使用頻率不匹配**：結算功能增加了系統複雜度，但實際使用場景有限
2. **使用者體驗問題**：自動結算提示可能干擾正常記帳流程
3. **維護成本考量**：結算相關程式碼分散在多個模組，增加維護難度
4. **回歸核心功能**：專注於記帳本質，餘額顯示已足夠

**備份分支：** `backup-before-cleanup`

**Rebase 指令：**

## 🚀 升級指南

### 開發者

**如果你有本地分支：**
```bash
# 1. 備份你的本地變更
git stash save "備份本地變更"

# 2. 強制更新到最新的 main
git fetch origin
git reset --hard origin/main

# 3. 恢復你的本地變更（可能需要解決衝突）
git stash pop
```

**如果你正在開發結算相關功能：**
- 該功能已被移除，請停止開發
- 如需保留，請 cherry-pick 到獨立分支
- 參考 `backup-before-cleanup` 分支的完整程式碼

### 使用者

**無需任何操作**
- Firebase 資料庫中的舊結算交易（如有）仍會保留
- 舊的結算交易會顯示為一般交易（金額為 0）
- 不影響任何現有記帳資料
