# v2 系列 - 功能擴展

**時間:** 2025-01-03 ~ 2025-01-04

---

## 📌 版本概述

大量功能擴展時期，新增多帳本管理、照片上傳、視覺化圖表、編輯功能等核心特性。專案從基礎記帳工具升級為功能完整的情侶記帳應用。

---

## 🎯 主要功能

### v2.0-2.3 早期功能
- 多帳本管理系統（日常、旅遊等）
- 日曆視圖優化（單日/月份模式）
- 分析頁面統計
- 刪除交易功能

### v2.4-2.7 媒體與視覺化
- 照片上傳功能（拍照或選擇相簿）
- 照片預覽與放大
- 備註功能
- 圓餅圖視覺化（分類統計）
- 設定頁面

### v2.8-2.9 進階操作
- 編輯交易功能（修改金額、分類等）
- 分類篩選
- 時間篩選

---

## 🛠️ 技術改進

- 照片處理與壓縮
- 圖表渲染（Chart.js）
- 複雜的篩選邏輯
- 表單驗證與錯誤處理
